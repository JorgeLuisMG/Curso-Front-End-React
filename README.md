# Curso de JavaScript y React

## 📝 Descripción
Este repositorio contiene una serie de proyectos y ejercicios desarrollados durante mi aprendizaje de JavaScript y React. El objetivo es mostrar mi progreso desde los conceptos fundamentales de JavaScript hasta la creación de aplicaciones con React.

## 💻 Tecnologías Utilizadas
- **Lenguaje:** JavaScript (ES6+)
- **Librería:** React
- **Herramientas de Desarrollo:** Vite, Node.js

---

## 📁 Contenido del Repositorio

### 1. Introducción a JavaScript (`Proyectos/1-intro-js`)

Esta sección cubre los conceptos básicos y fundamentales de JavaScript. Cada archivo se enfoca en una característica específica del lenguaje:

- **`01_Strings.js`**: Manejo de strings, plantillas literales (template literals) y declaración de variables.
- **`02_Funciones.js`**: Creación de funciones tradicionales y asignación de parámetros por defecto.
- **`03_Funcion_Flecha.js`**: Uso de funciones de flecha (arrow functions) para una sintaxis más concisa.
- **`04_Objeto.js`**: Declaración y modificación de objetos literales.
- **`05_Objetos_Relacionados.js`**: Creación de objetos anidados y métodos dentro de un objeto.
- **`06_Objetos_Arreglos.js`**: Manipulación de arreglos (arrays) dentro de objetos y métodos para iterar sobre ellos.

## 🚀 Instrucciones de Uso

Los proyectos en este repositorio utilizan **Vite** como herramienta de construcción. Sigue estos pasos para ejecutar cualquiera de los proyectos.

### Prerrequisitos
- Tener **Node.js** y **npm** instalados. Puedes descargarlos desde [nodejs.org](https://nodejs.org/).

### Instalación

1.  **Clona el repositorio** en tu computadora:
    ```sh
    git clone https://github.com/JorgeLuisMG/Curso-Front-End-React.git
    ```
2.  **Navega a la carpeta** del proyecto que deseas ejecutar (por ejemplo, `1-intro-js`):
    ```sh
    cd Curso-Front-End-React/Proyectos/1-intro-js
    ```
3.  **Instala las dependencias** del proyecto:
    ```sh
    npm install
    ```

### Ejecución
1.  Una vez instaladas las dependencias, ejecuta el siguiente comando para iniciar el servidor de desarrollo:
    ```sh
    npm run dev
    ```
2.  Abre la consola de tu navegador para ver los resultados de los scripts de JavaScript.
